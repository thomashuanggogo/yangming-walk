# 陽明里漫步指南 - 2D 手機直立式文化探索遊戲

專為**台北市士林區陽明里（山仔后地區）**量身打造的 2D 歷史文化導覽遊戲。採用純靜態 Web 架構，完全支援智慧型手機直立操作（包含透過 LINE 點開即玩），並可直接部署至 **GitHub Pages** 免費供全體里民與遊客探索遊玩。

---

## 遊戲核心特色

1. **純手繪全景地圖與 30 處核心地標**：
   * 搭載全新繪製之吉卜力風格水彩全景底圖，完整收錄全里 30 處文史建物、自然生態與山仔后生活核心。
   * 30 處地標皆具備獨立手繪去背小圖（Vignette Icons），靠近即時彈出精美文化導覽卡片與專屬特色標籤。
2. **手繪水彩文史圖鑑冊（Illustrated Album）**：
   * 點擊右上角「圖鑑」隨時翻開典藏畫冊，支援五大分區（中央、北區、西區、東區、南區）即時篩選。
   * 探索進度自動保存於瀏覽器 LocalStorage，重整或關閉網頁進度不遺失。
   * 全數收集 30 處地標後，自動加蓋金色「全通關達成」榮譽火漆印章。
3. **零安裝、點開即玩**：
   * 無需下載 App 或註冊帳號，任何手機點擊網址 1 秒內即刻載入。
4. **手機直立操作與長輩友善設計**：
   * **點擊尋路（Tap-to-Move）**：手指直接輕點地圖上的任何地方，角色就會自動漫步走過去。
   * **虛擬手把（D-pad）**：提供螢幕下方的復古方向鍵與「調查 / 對話」大按鈕。
   * **電腦端相容**：電腦瀏覽器支援鍵盤 `[W][A][S][D]` 或 `[方向鍵]` 移動，`[E]` 或 `[空白鍵]` 互動。
5. **里民榮譽認證與社群分享**：
   * 走訪完成 30 大核心地標後，自動頒發「陽明里榮譽文史漫遊者」數位認證，附帶一鍵複製連結功能，便於轉發至里民 LINE 群組。

## 本地預覽與測試方式

本專案採用現代原生 ES6 模組（`type="module"`），推薦透過任何輕量靜態伺服器開啟：

### 方法一：使用專案內建 Node.js 伺服器
`ash
node serve.js
`
開啟瀏覽器前往：`http://localhost:3000`

### 方法二：使用 Python 內建伺服器
`ash
python -m http.server 8080
`
開啟瀏覽器前往：`http://localhost:8080`

## GitHub Pages 免費發布步驟

1. **建立 GitHub 倉庫**：
   * 前往 GitHub 建立一個公開倉庫（例如：`yangming-walk`）。
2. **推送到 GitHub**：
   `ash
   git remote add origin https://github.com/<您的帳號>/yangming-walk.git
   git branch -M main
   git push -u origin main
   `
3. **啟用 GitHub Pages**：
   * 進入倉庫的 **Settings** ➔ **Pages**。
   * 在 **Build and deployment** 下方的 **Branch** 選擇 **main**，資料夾選擇 **/ (root)**，點擊 **Save**。
   * 等待約 1 分鐘即可取得專屬公開網址：
     `
     https://<您的帳號>.github.io/yangming-walk/
     `
4. **分享至 LINE 社群**：
   * 將網址發布至里民群組，里民點擊即可立即在手機上暢玩。
